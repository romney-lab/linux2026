# 我对GenAI的观点

- 学习GenAI首先是需求问题，免费网页版豆包对话助手能解决我遇到的绝大多数问题，至于为何要使用多种AI assistant，甚至复古使用传统搜索引擎，是因为各有所长
- 我个人使用过的agent有Claude Code和OpenCode，接入过的LLM有Minimax和DeepSeek，但我感觉所解决的需求大多不是必须要agent才能完成的，而且我的使用方法有点像玩具，虽说不那么氛围编程。最近斯坦福大学计算机系著名课程《现代软件开发者》大幅更新了，有意思
- 对于按token计费的方案，我喜欢省token，用agent肯定不能像用assistant那样玩耍
- 对于近年涌现的一系列新的概念，如skill、loop等，我感觉不是什么开创性的事物，似乎有些“为百合镀金”。因为我不认为自己很了解这些，我没用过skill，所以只能说“我感觉”
